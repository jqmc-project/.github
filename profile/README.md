# jQMC project

Open-source ab initio quantum Monte Carlo (QMC).
[jQMC](https://github.com/jqmc-project/jQMC) runs variational Monte Carlo (VMC) and lattice-regularized
diffusion Monte Carlo (LRDMC) for molecules and periodic solids, on GPUs with JAX and on CPUs with Rust kernels.
The other repositories add workflow automation, validation and published data around it.

| Repository | What it is | Documentation |
|---|---|---|
| [jQMC](https://github.com/jqmc-project/jQMC) | The QMC code: VMC and LRDMC for open-boundary and periodic systems | [jqmc-project.github.io/jQMC](https://jqmc-project.github.io/jQMC/) |
| [aiida-jQMC](https://github.com/jqmc-project/aiida-jQMC) | AiiDA plugin: jQMC calculations with full provenance, checkpoint restarts and structured output | [jqmc-project.github.io/aiida-jQMC](https://jqmc-project.github.io/aiida-jQMC/) |
| [aiida-jQMC-LLM-agent](https://github.com/jqmc-project/aiida-jQMC-LLM-agent) | AiiDA work chains whose parameter decisions are taken by a language model from written know-how (in preparation) | README |
| [jQMC-benchmark](https://github.com/jqmc-project/jQMC-benchmark) | Validation and benchmark collections for jQMC (in preparation) | README |
| [jQMC-data](https://github.com/jqmc-project/jQMC-data) | Supplementary calculation data (inputs, outputs, analysis scripts) for jQMC papers | README |
